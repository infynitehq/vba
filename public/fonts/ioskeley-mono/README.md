# Ioskeley Mono

Source: https://github.com/ahatem/IoskeleyMono/releases/latest/download/IoskeleyMono-Web.zip

Normal-width web subset, downloaded 2026-11-05. Only the four upright weights used by the app are bundled. Licensed under SIL OFL 1.1; see `LICENSE`.

Fonts are served from `public/fonts` through the shared `public/fonts.css` stylesheet used by both the app and player iframe, and precached by the service worker for offline use.
